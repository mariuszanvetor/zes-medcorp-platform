## Repair Recommendations

1. Prioritize source-spec extraction for products where the source page appears richer than the imported page, especially monitoring, laboratory and emergency products.
2. Require at least 7 imported specifications for equipment products before considering indexation; consumables may use a lower threshold only when package, size, sterility and document data are complete.
3. Add dimensions and weight wherever the source page provides them. Products missing both should remain noindex.
4. Split identity specs from technical specs. `Cod produs` and `Categorie` should not count toward technical completeness.
5. For product families, create category-specific spec templates: centrifuges, analyzers, monitors, trolleys/stretchers, autoclaves/sealers.
6. Do not invent specifications. If source specs are unavailable, keep the product noindex and show only source-confirmed documents/features.
7. Re-run this audit after each repair batch and only consider indexation for products graded A or B.
