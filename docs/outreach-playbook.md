# Outreach Playbook

This playbook defines the internal outreach approach for ZES MEDCORP. It is designed for professional B2B conversations, not mass outreach.

## Positioning

ZES should be presented as a technical planning partner for:

- medical infrastructure
- imaging rooms
- RF shielding
- radioprotection
- clinic planning
- IVD / laboratory planning
- service and uptime

The message is simple:

> We help teams turn a rough project idea into a structured technical discussion.

## Who to contact

Priority audiences:

- private clinic owners
- imaging center managers
- radiologists and medical leads
- healthcare architects
- technical project managers
- medical construction firms
- hospital administrators
- procurement / operations stakeholders

## Outreach principles

- Start with relevance, not a pitch.
- Be specific about the technical problem.
- Mention one useful resource, not five.
- Do not send bulk messages.
- Do not copy the same message to unrelated contacts.
- Do not claim certainty where the project still needs validation.

## Best entry points

- A calculator relevant to their project
- A comparison page that clarifies a common decision
- A glossary term that removes confusion
- A planning page that shows the next step
- Proposal Builder when the project is already well defined
- Project Intake when the project needs structure

## Follow-up timing

- First follow-up: 3 to 5 business days
- Second follow-up: 7 to 10 business days after the first
- Third follow-up: only if there is a real technical reason to continue

## How to avoid spam

- Send only to relevant contacts.
- Reference the specific project type.
- Use one clear CTA.
- Keep messages short.
- Stop if the contact is not a fit.
- Do not automate mass connection requests or repetitive follow-up sequences.

## Demo positioning

When useful, mention one of these:

- calculator for an early estimate
- Project Intake for structured data
- Proposal Builder for preliminary planning
- comparison page for decision support

The goal is to move the conversation from vague interest to a technical next step.

## Conversion path

1. LinkedIn connection or message
2. Relevant calculator / comparison / glossary
3. Project Intake or Proposal Builder
4. Direct consultation

## Semi-automated prospecting engine

For manual prospecting operations, use the workbook and workflow described in
[`docs/semi-automated-lead-prospecting.md`](./semi-automated-lead-prospecting.md).

The local engine:

- prepares daily queues, scoring and templates;
- does not send emails;
- does not scrape aggressively;
- does not invent contact data;
- blocks outreach until a public business contact is verified;
- treats opt-out as a priority rule.
