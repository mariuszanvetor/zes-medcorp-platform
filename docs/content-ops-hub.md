# Content Ops Hub

The internal Content Ops Hub is a working surface for the ZES MEDCORP team to manage LinkedIn ideas, manual outreach, and content promotion without turning the process into automation or spam.

## What the page is for

- Choosing a suggested LinkedIn post for the day
- Reviewing the 30-day publishing mix
- Matching each post to a useful URL
- Keeping outreach human and relevant
- Reusing approved message templates

## Daily routine

1. Open the internal content ops page.
2. Pick one LinkedIn idea that fits the current project mix.
3. Copy the draft or edit it manually.
4. Open the recommended URL and make sure it matches the post.
5. Send a small number of relevant connection requests.
6. Use one or two warm follow-ups only when there is a real signal.
7. Promote one calculator, comparison, glossary page, or planning page.
8. Check Search Console, Resend, Google Sheets, and the admin lead monitors.

## Outreach routine

- Keep the first contact short.
- Reference the project context, not a generic sales pitch.
- Avoid mass messaging.
- Avoid repeated follow-ups if there is no signal.
- Use Proposal Builder or Project Intake only when the discussion is ready for structure.

## How to choose URLs

Use the most specific useful page:

- calculators for estimation and planning questions
- comparisons for decision support
- glossary terms for definition clarity
- planning pages for project-stage guidance
- Proposal Builder when the discussion is ready for a structured proposal
- Project Intake when the prospect needs to organize the project first

## How to measure progress manually

- Posts published per week
- Connections accepted
- Warm replies
- Calculator clicks
- Proposal Builder starts
- Project Intake starts
- Lead submissions

## Weekly review

- Review which post categories performed best.
- Check whether outreach stayed relevant.
- Update the next week&apos;s mix to keep it balanced.
- Avoid repeating the same hook or CTA too often.

## Safety rules

- No automated sending.
- No mass outreach.
- No fake testimonials.
- No fake case studies.
- No public navigation link.
- No sitemap entry.
- Admin access remains protected by the existing password gate.
