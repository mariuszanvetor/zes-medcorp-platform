# LinkedIn Content Strategy

This document defines the LinkedIn operating system for ZES MEDCORP. The goal is consistent authority distribution, not spam.

## Purpose

LinkedIn should help ZES:

- stay visible in the technical and B2B conversation
- explain infrastructure decisions in plain language
- route serious prospects to calculators, glossary pages, comparisons, planning pages, Proposal Builder and Project Intake
- build trust before the first sales conversation

## Content pillars

1. Medical infrastructure planning
2. RMN / RF shielding
3. CT / radioprotection / CNCAN
4. Imaging equipment selection and integration
5. IVD / laboratory planning
6. Service, uptime and maintenance
7. Clinic modernization
8. Project qualification and lead readiness

## Post formats

- Educational explainer
- Technical clarification
- Planning mistake / lesson learned
- Comparison summary
- Calculator-driven insight
- Project readiness prompt
- Glossary explanation
- Service / uptime note

## Link ecosystem

Every post should link to one primary destination only.

Recommended destinations:

- calculators: `/calculatoare/...`
- glossary: `/glosar/...`
- comparisons: `/comparatii/...`
- planning hub: `/planificare`
- Proposal Builder: `/proposal-builder`
- Project Intake: `/project-intake`
- services: `/services/...`

## Editorial rules

- One idea per post.
- Keep the tone professional and B2B-appropriate.
- Do not invent client stories, certifications, approvals or exact commercial guarantees.
- Do not overuse buzzwords.
- Use specific examples: RF shielding, HVAC, calibration, downtime, flow, authorization, integration.
- End with a useful next step, not a hard sell.

## Recommended cadence

- 2 posts per week
- 1 deeper technical post
- 1 practical planning or conversion-oriented post

## How to use the dataset

The reusable idea bank lives in `src/data/linkedin-posts.ts`. It can be used later to:

- queue posts by theme
- map CTA targets
- support campaign planning
- select visuals
- create monthly calendars

## CTA hierarchy

Use the weakest CTA that still helps the reader:

1. Read a glossary term
2. Open a comparison
3. Use a calculator
4. Open Planning
5. Start Project Intake
6. Open Proposal Builder
7. Contact ZES

## Quality bar

Each post should answer at least one of these:

- What changes the budget?
- What changes the calendar?
- What needs validation first?
- What is easy to confuse?
- What is the safest next step?
