Subiect: Activare abonament ZES CabinetCare

Bună ziua,

În urma auditului, vă propun activarea abonamentului ZES CabinetCare [Basic / Standard / Premium].

- evidență aparatură;

- suport tehnic;

- coordonare furnizori/service autorizat unde este cazul;

- contract minim recomandat: 3 luni;

- intervențiile peste orele incluse se facturează separat;
- deplasările în afara București-Ilfov se ofertează separat.
